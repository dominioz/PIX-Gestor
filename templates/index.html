📖 Documentação Técnica, Testador Interativo e Exemplos de Uso

A API gera o código PIX Copia e Cola ou a Imagem PNG do QR Code estático EMV. O parâmetro descricao é mapeado para o campo TxID do PIX (identificador do extrato bancário).

⚡ Testar Geração em Tempo Real
QR Code Gerado:
Código Copia e Cola (Payload):
1. Parâmetros Aceitos nas Rotas
Parâmetro Tipo Obrigatório Descrição
api_key String Sim Sua chave única de autenticação de API.
valor Decimal/Float Sim Valor a ser cobrado. Exemplo: 10.50 ou 10,50.
descricao String Não Identificador da transação (TxID) que sairá no extrato. Aceita apenas letras e números (máx. 25 caracteres). Se omitido, usará ***.
2. Exemplos Atualizados com os Valores do Formulário acima:
🔹 Obter Imagem do QR Code (PNG)

Endpoint: GET /qrcode

GET {{ request.host_url }}qrcode?api_key={{ usuario_logado.api_key }}&valor=25.00&descricao=PEDIDO123
Exemplo de inclusão em tag HTML: 
<img src="{{ request.host_url }}qrcode?api_key={{ usuario_logado.api_key }}&valor=25.00&descricao=PEDIDO123" alt="QR Code PIX" />
🔹 Obter Payload (PIX Copia e Cola em JSON)

Endpoint: GET /payload

GET {{ request.host_url }}payload?api_key={{ usuario_logado.api_key }}&valor=25.00&descricao=PEDIDO123
Retorno JSON de Exemplo: 
{
  "status": "sucesso",
  "pix_copia_cola": "000201..."
}
3. Criar Cobrança e Enviar E-mail via API

Endpoint: POST /cobranca/criar

Aceita requisições no formato JSON ou Form-Data. Cria o registro no sistema, gera o PIX e envia o e-mail de cobrança automaticamente para o cliente.
